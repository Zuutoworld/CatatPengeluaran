# CatatDuit 💰

Aplikasi pencatat pengeluaran harian. Gratis, tanpa backend, data tersimpan di browser.

## Fitur

- ✅ Tambah, edit, hapus pengeluaran
- 📅 Pencarian per tanggal (riwayat hari-hari sebelumnya tetap tersimpan)
- 📊 Grafik pengeluaran (kategori & harian)
- 🔍 Filter & pencarian
- 🌙 Dark / Light mode
- 🌐 Bilingual (Indonesia / English)
- 📱 Share ke WhatsApp
- 💾 Data tersimpan di LocalStorage browser

## Tech Stack

- HTML5
- Tailwind CSS v4 (CDN)
- Vanilla JavaScript
- Chart.js

## Deploy (Gratis!)

### Cara 1: Vercel

1. Push ke GitHub
2. Buka [vercel.com](https://vercel.com)
3. Import repository
4. Deploy! ✅

### Cara 2: GitHub Pages

1. Push ke GitHub
2. Settings → Pages → Source: `main` branch
3. Selesai!
